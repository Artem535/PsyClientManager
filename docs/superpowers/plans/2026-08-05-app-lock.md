# App Lock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a PIN/password application lock, automatic locking, and safe clipboard clearing without encrypting the active database.

**Architecture:** `AppLockService` owns an Argon2id verifier stored in QSettings. `AppLockController` evaluates activity and lock policy, while `Application` presents a modal lock dialog. `SensitiveClipboardService` clears only clipboard text that it wrote and that the user has not replaced.

**Tech Stack:** C++20, Qt Widgets, QSettings, libsodium, GoogleTest.

## Global Constraints

- Persist only salt, Argon2id verifier, and KDF parameters; never log credentials.
- PIN requires six digits; password requires twelve characters.
- After five failures, delay attempts for 30 seconds and double delays to five minutes.
- Timeout `0` permits manual lock only; background inactivity must be at least one minute.
- Never clear clipboard content copied by the user after the application copy.
